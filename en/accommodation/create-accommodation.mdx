## Create accommodation

### Step 1. Search for the property

Search for the property name of the accommodation you operate.

<Info>
  The search fills in the property name and address for you. If your property isn't on the list, select 'Enter manually' and register the details yourself.
</Info>

### Step 2. Enter the basic information

Fill in the basic details.

<Info>
  **Basic information**

  - Name: enter the accommodation's registered business name.
  - Address: filled in by the search, and you can edit it if needed.
  - Accommodation type: used only for classification inside VENDIT. It has no effect on how the service works.
  - Default check-in and check-out times: when a channel's Booking info has no times, the values you set here are applied as the default.
</Info>

### Step 3. Create room types

Add the room types you currently operate at your accommodation.

<Info>
  Room types can be added and edited later.
</Info>

### Step 4. Set max occupancy and number of rooms

For each room type, enter the max occupancy and how many rooms you operate.

<Info>
  **Room type setup guide**

  - Max occupancy: the highest number of guests who can stay in that room type. It is the basis for the Extra guest charge.
  - Number of rooms: the physical rooms you actually operate. It is the basis for Inventory.
</Info>

### Step 5. Create packages

Create the packages you want to sell. Even within one room type, you can split packages by the inclusions or the conditions of use.

<Info>
  **Package setup guide**

  - Room only: the basic package, the overnight stay and nothing else.
  - Packages with inclusions: create separate packages that include breakfast, parking, bundles, or other add-ons. Several packages can share one room type and sell at different rates.
</Info>

### Step 6. Accommodation created

Your accommodation is registered. Connect the channels you use and they sync with VCMS immediately.

<Info>
  Everything you entered can be changed later in the accommodation settings. Room types and packages can be added or deleted too.
</Info>
