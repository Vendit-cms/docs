## Accommodation settings

### Basic information

- Name: edit the accommodation's name, type, and address.
- Notification contacts: set the default contact that receives VCMS notifications.
  - Adding contacts beyond the default one is a paid change.

### Currency

- Set the currency the accommodation mainly works in.
- Choose how rates are rounded: Round, Round up, or Round down. The rounding you pick applies to Distribution immediately.

### Default overnight and day use timetables

- When a booking comes in from a channel without check-in and check-out times, the default timetable is applied.
  - Edit info lets you set different default times for each day of the week.
- Check-in and check-out times can also differ per package, for cases like early check-in and late check-out.
  - [See the timetable guide🔗](https://docs.vcms.io/en/inventory-rate/timetable)
