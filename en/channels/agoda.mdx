## Things to watch

### Set occupancy-based pricing in VCMS

Agoda prices against occupancy. Any package you connect to Agoda has to have occupancy-based pricing set in VCMS.

<Warning>
  **On occupancy-based pricing**

  - Set occupancy-based pricing on a channel that does not support it and the rate is applied against max occupancy. If that is not what you want, split the packages by whether the channel supports occupancy-based pricing.
    - Channels without occupancy-based pricing
      - Yanolja, Yeogi Eottae owner app, Yeogi Eottae Partner Center, Kkulstay, Naver, Ddananyo, Onda, Tripbtoz
      - Trip.com and Expedia vary by contract.
  - VCMS supports occupancy-based pricing for adults. Set child rates directly in YCS.
</Warning>

---

### Connecting several Agoda packages to one room type means matching their inventory

When several Agoda packages hang off the same room type, availability is controlled at the room type level, so each package has to carry the same inventory.

<Warning>
  This holds even with auto top-up switched on in VCMS. Set the same quantity on every package. Different quantities keep moving availability around and inventory drifts out of line.
</Warning>

## FAQ

### Where do I set Agoda child rates?

In YCS, directly.

<Info>
  Path: \[YCS\] - \[Property\] - \[Room settings\] - \[Allow children\]
</Info>

---

### The integration works but my packages are not showing on Agoda's booking site.

Check in YCS whether a rate plan is attached and whether the package is on sale. Without a rate plan, or in any state other than on sale, the package cannot sell.

<Accordion title="Checking whether a rate plan is attached">
  📍Path: \[YCS\] - \[Rates & availability\] - \[Rate plan settings\]

  <Frame>

  </Frame>
