## Tripdotcom integration setup

<Info>
  For properties that can set availability per package on the Tripdotcom room calendar, connecting a channel manager switches the availability basis to room type automatically.

  - In that switch, per-package inventory merges into room type inventory, the availability resets, and Stop sell applies. If your accommodation can set availability per package, be sure to read the examples below.
</Info>

## Things to watch

<Info>
  Tripdotcom is a channel that **syncs only Booking info created or changed after the channel connects**.

  Connect VCMS while already using Tripdotcom and bookings made before the connection do not sync automatically. Those bookings must be Managed in channel.

  Tripdotcom bookings created or changed after the VCMS connection sync normally.
</Info>
