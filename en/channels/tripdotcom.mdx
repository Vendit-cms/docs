## Trip.com integration setup

<Info>
  For properties that can set remaining allotment per package on the Trip.com room calendar, connecting a channel manager switches the allotment basis to room type automatically.

  - In that switch, per-package inventory merges into room type inventory, the remaining allotment resets, and Stop sell applies. If your property sets allotment per package, read the examples below first.
</Info>

## Things to watch

<Info>
  Trip.com is a channel that **syncs only bookings created or changed after the channel connects**.

  Connect VCMS while already using Trip.com and bookings made before the connection do not sync. Those you manage yourself.

  Trip.com bookings created or changed after the VCMS connection sync normally.
</Info>
