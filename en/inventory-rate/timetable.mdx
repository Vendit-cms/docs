### Timetable list

![Timetable list](/images/en-timetable-list.png)

<Check>
  Different packages can run on different check-in and check-out times.

  - Reorder timetables freely.
  - The default timetable is changed on the accommodation information page.
  - Day use timetables are not supported yet.
</Check>

<Note>
  **The times you enter reach only the channels that support check-in and check-out times.**

  - Yeogiottae owner app (motels)
  - Yanolja (motels, hotels, guest houses)
  - Coolstay (motels, hotels, pensions)
</Note>

### Creating a timetable

![Creating a timetable](/images/en-timetable-create.png)

<Check>
  Add timetables beyond the default one.

  - **_Timetable name (required)_**
  - **Import an existing timetable**
    - Pull in the accommodation's default timetable, or one you built earlier.
  - **Check-in and check-out times**
    - Set them separately for each day, Sunday through Saturday.
  - **Apply to selected days**
    - Copy one time and apply it to the days you select.
</Check>

![Timetable weekday settings](/images/판매시간표_3.png)

### Connecting a timetable to packages

![Connecting a timetable to packages](/images/판매시간표_4.png)

<Check>
  A timetable supplies the default check-in and check-out times for the packages connected to it.

  - Turn `Connect packages` on to link the timetable you created to packages.
</Check>

### Deleting a timetable

![Deleting a timetable](/images/en-timetable-delete.png)

<Check>
  Delete a timetable and every package using it falls back to the default timetable.
</Check>

![Timetable deletion confirmation](/images/판매시간표_6.png)
