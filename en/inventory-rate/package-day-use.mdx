  - See every day use package created against a room type.

</Check>

### Creating a day use package

![Creating a day use package](/images/en-dayuse-create.png)

<Check>
  Create the day use packages you need.

  - **Package name (required)**
  - **Room type (required)**
    - Pick the room type to link.
    - Once the day use package exists, its room type cannot be changed.
</Check>

<Note>
  **Day use packages currently support booking sync only. Inventory and Rate features are not supported.**
</Note>

### Deleting a day use package

![Deleting a day use package](/images/en-dayuse-delete-icon.png)
