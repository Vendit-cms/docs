## Rates

![Distribution overview, rates](/images/판매관리이해하기_요금.png)

<Info>
  How rates are displayed: in Korean won (KRW), anything above the thousand mark is abbreviated with 만.

  - Locked rate
    - Excluded from daily rate adjustments, room type rate adjustments, and bulk updates.
  - Fixed rate
    - Packages with a fixed rate cannot have their rate changed from Distribution.
  - Occupancy-based pricing
    - Shows the rates that apply as guest count moves between base occupancy and max occupancy.
  - Rate period
    - Shows which period applies on a given date.
</Info>

<Check>
  **Running a "business special" package that sells at one rate all year?**

  - Set the package rate to Fixed rate. It then holds the same price, untouched by period rates or any markup and discount.
</Check>

## Availability

![Distribution overview, availability](/images/판매관리이해하기_잔여.png)

<Info>
  Set how much of a package is left to sell.

  - Availability updates in real time as sales come in.
  - Availability is linked across room type, package, and channel package.
    - Room type: availability is based on the number of rooms. ⮑ Package: availability is based on the inventory of the room type it is connected to. ⮑ Channel package: availability is based on the inventory of the package it is connected to.
</Info>
