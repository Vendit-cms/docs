---
title: "Can I use it on mobile?"
description: "Yes, mobile works."
---

<Check>
  There is no mobile app yet.

  - Open https://vcms.io on a mobile device and you can adjust inventory and rates.
  - Mobile carries a reduced set of controls, so use a PC for everything except inventory and rate changes on the Distribution screen.
</Check>

## PC and mobile compared

### Distribution

|  | `💻 PC` | `📱 Mobile` |
| :-: | :-: | :-: |
| Sell status | O | O |
| Availability | O | O |
| Check-in/out times | O | X |
| Rates | O | O |
| Bulk update | O | X |
| <Tooltip tip="Pick which columns appear on screen.">View settings</Tooltip> | O | X |
| Filters | O | X |

<Note>
  Mobile supports changing sell status, availability, and rates.
</Note>
