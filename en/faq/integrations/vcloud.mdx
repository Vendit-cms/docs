### Integration `admin` manual

![Integrations screen](/images/en-integrations.png)

<Check>
  Go to Settings > Integrations.
</Check>

![Entering the accommodation ID](/images/연동서비스_2.png)

<Check>
  Enter the accommodation ID VCLOUD uses.

  - The accommodation ID is in the VCLOUD URL.
</Check>

### When the VCLOUD connection fails

![VCLOUD connection failure](/images/연동서비스_5.png)

<Warning>
  An incorrect accommodation ID leaves the connection failed with an "accommodation ID error".

  - Press `Reconnect` and enter the correct accommodation ID.
</Warning>

### Disconnecting VCLOUD

![Disconnecting VCLOUD](/images/연동서비스_4.png)

<Danger>
  Every booking record from the integration is deleted and channel package availability changes.

  - This cannot be undone. Be careful.
</Danger>
