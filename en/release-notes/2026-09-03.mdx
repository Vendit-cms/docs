> **Highlights**<br />"Apply one package's rate periods to other packages in a single pass."

## New

### Apply rate periods to other packages at once

> For properties that set the same rate periods across many packages

<Frame>
  ![Bulk update rate plan modal](/images/en-260903-bulk-apply-modal.png "Bulk update rate plan modal")
</Frame>

On the Settings > Packages > Rate plan tab, rate periods set on one package can be copied to others. Instead of repeating the same periods package by package, the period structure moves across as it is.

- **Bulk apply rate periods**: from the option (⋮) menu at the top of the list, pick one package to copy from and apply it to many at once.
  <Frame>
    ![Bulk update rate plan button](/images/en-260903-bulk-apply-button.png "Bulk update rate plan button")
  </Frame>

- **Import rate periods**: the "Import" button on a package card pulls another package's rate periods into this one.
  <Frame>
    ![Import rate plan button](/images/en-260903-import-rate-plan.png "Import rate plan button")
  </Frame>

<Info>
  **What copies is the "period structure and rate adjustments", not the amounts**

  - The final rate is recalculated by applying the adjustments to each package's own rate. A package's base rate never moves.
  - Periods that exist only on the receiving package are kept, and rates you changed individually are kept too.
  - A calculated rate that falls outside the package's minimum or maximum is automatically pulled back inside the range.
  - Packages on a fixed rate, packages with no rate set, and packages in a different currency are excluded, and the list says why.
</Info>

### Adding a period to a package is easier

> For properties tired of linking periods one package at a time

- **Add to several packages at once**: if a period is linked to no package at all, an "Add {N} unlinked periods" link appears at the top of the list. An unlinked period sells at the base rate for those dates, so check it when you see the link.
  <Frame>
    ![Add multiple periods](/images/en-260903-add-multi-period.png "Add multiple periods")
  </Frame>
  ![Add multiple periods modal](/images/en-260903-add-multi-period-modal.png "Add multiple periods modal")
- **Add to a single package**: the "Add period" button on a package card picks a period from the periods page. The adjustment stored on the period comes across as the starting value.
  <Frame>
    ![Add a period to one package](/images/en-260903-single-add-period.png "Add a period to one package")
  </Frame>
- An added period slots in at its priority position from the periods page.

<Warning>
  If a period you add overlaps one already there, the higher period wins and the rate can change. Check each package's rate before you save.
</Warning>

---

### Align period order with the periods page in one step

A package's rate period order can be brought in line with the priority on the periods page. When periods overlap the higher one applies first, so an order out of step can sell at a rate you did not intend.

<Check>
  Only the order changes. No period is added or removed, and no rate or adjustment is touched.
</Check>

- For every package, run "Align period order" from the option (⋮) menu.

<Frame>
  ![Align order across packages](/images/en-260903-bulk-align-button.png "Align order across packages")
</Frame>

<Info>
  Packages already in the right order are skipped.
</Info>

- For one package, use the "Align order" button on the card.

<Frame>
  ![Align order on one package](/images/en-260903-single-align-order.png "Align order on one package")
</Frame>

## Improvements

### Expand and collapse rate plans in one go

"Expand all | Collapse all" at the top of the package list opens or closes the rate plan for every package at once. With many packages, you reach the one you want quickly.

<Frame>
  ![Expand and collapse button](/images/en-260903-expand-collapse.png "Expand and collapse button")
</Frame>

### Select several room types in the filter

The room type chips at the top take more than one selection, so you can pull up just the types you want and compare them on one screen.

<Frame>
  ![Multi-select room type filter](/images/en-260903-roomtype-filter-multi.png "Multi-select room type filter")

### Undo temporary changes

Everything you do on the Rate plan tab (bulk apply, import, adding periods, aligning order, editing rows) lands on screen as a temporary change first. Check it, then press "Save" in the top bar to commit.

<Frame>
  ![Undo provisional changes](/images/en-260903-temporary-change-bar.png "Undo provisional changes")
</Frame>

- A changed package card carries a "Temporary change" badge, and the changed cells and order are highlighted.
- The Undo (↩︎) button on a card reverts only that package's changes to their pre-save state.
- Leaving the page without saving warns you that the changes will be lost.
