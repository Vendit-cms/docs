> **Highlights**<br />"Properties that use inventory only no longer have the channel's unconfigured packages opened automatically."

## Fixes

### Unconfigured packages no longer open automatically at properties that use inventory only

> For properties using Inventory without Rate

At properties running Inventory without Rate, VCMS was opening the channel's unconfigured packages automatically. Fixed. Unconfigured packages now stay closed, and you can manage when they go on sale and their rate settings directly in the channel.

<Info>
  **What is an unconfigured package?**

  A package that has not been registered for sale on the channel yet. It is not sold on the guest-facing site. It shows up like this on the channel's Distribution screen, for example the NOL Partner Center.
