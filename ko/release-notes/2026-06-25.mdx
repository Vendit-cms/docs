> **주요 업데이트 미리보기**\
> "채널에서 숙소가 비활성화·삭제되면 연결을 자동으로 해제해 잘못된 동기화를 막아드립니다."

## 신규 기능

### 채널에서 숙소가 비활성화·삭제되면 숙소 연결을 자동으로 해제해 드려요

연결된 채널에서 해당 숙소가 비활성화·삭제되거나 공식 연동이 허용되지 않는 상태가 감지되면, 잘못된 예약·요금 동기화를 막기 위해 VCMS가 그 채널 숙소의 연결을 자동으로 해제합니다. 연결이 해제되면 작업 이력이 기록되고, VCMS 알림과 카카오톡 알림으로 안내해 드립니다.

**더 알아보기**

- 적용 채널: 아고다, 트립닷컴, 야놀자(숙소 미노출·가맹 해지 시)
- 적용 채널은 앞으로 순차적으로 확대될 예정입니다.

<Info>
  자동으로 해제된 연결은 다시 자동으로 연결되지 않습니다. 채널에서 숙소 상태를 정상화하셨다면, VCMS에서 직접 재연결해 주세요.
</Info>
