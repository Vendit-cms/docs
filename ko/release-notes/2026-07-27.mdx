> **주요 업데이트 미리보기**<br />"재고 관리만 사용하는 업장은 이제 채널의 미설정 재고를 자동으로 열지 않아요."

## 변경 사항

### 재고 관리만 사용하는 업장의 미설정 재고 처리 방식이 바뀌었어요

> 추천 대상: 요금 관리 없이 재고 관리만 사용하는 숙소

이제 요금 관리를 사용하지 않고 재고 관리만 사용하는 업장은, 채널의 **미설정 재고**를 VCMS에서 제어하지 않습니다.

<Info>
  **미설정 재고란?**

  채널에서 예약 사이트에 오픈하기 전 상태의 재고를 말합니다. 실제 예약자 사이트에는 판매되지 않습니다.
</Info>

**무엇이 달라졌나요?**

기존에는 재고 관리만 사용하는 업장이라도 채널의 미설정 재고를 한 번에 열어 드렸습니다. 이때 요금 관리를 사용하지 않는 업장에서는 다음과 같이 요금이 설정되는 문제가 있었습니다.

- 채널별 최소 금액 기준이 설정되어 있는 경우: 최소 금액으로 설정
- 채널별 최소 금액 기준이 설정되어 있지 않은 경우: 0원으로 설정

앞으로는 재고 관리만 사용하는 업장의 미설정 재고를 VCMS에서 자동으로 열지 않아, 의도하지 않은 금액으로 판매되는 상황을 방지합니다.
