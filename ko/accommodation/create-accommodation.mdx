## 숙박업소 생성

### Step 1. 숙소 검색

운영 중인 숙박업소 이름을 검색해 주세요.

<Info>
  검색 시 숙박업소명, 주소가 자동으로 입력됩니다. 목록에 없는 업소라면 '직접 입력'을 선택해 정보를 수동으로 등록할 수 있어요.
</Info>

### Step 2. 기본 정보 입력

기본 정보를 입력합니다.

<Info>
  **기본 정보**

  - 이름: 숙박업소의 실제 상호명을 입력해 주세요.
  - 주소: 검색으로 자동 입력되며, 필요 시 직접 수정할 수 있어요.
  - 숙박업소 유형: 서비스 기능에는 영향을 주지 않으며, 벤디트 내 분류 목적으로만 사용됩니다.
  - 기본 입·퇴실 시간: 채널별 예약 정보에 시간이 없을 경우 여기서 설정한 값이 기본값으로 적용돼요.
</Info>

### Step 3. 객실 타입 생성

숙박업소에 운영 중인 객실 타입을 추가해 주세요.

<Info>
  객실 타입은 나중에도 추가·수정할 수 있어요.
</Info>

### Step 4. 객실 타입 최대 인원 및 객실 수 설정

각 객실 타입의 최대 수용 인원과 운영 중인 객실 수를 입력해 주세요.

<Info>
  **객실 타입 설정 가이드**

  - 최대 인원: 해당 타입에 숙박 가능한 최대 인원 수입니다. 인원 초과 요금을 판단하는 기준이 됩니다.
  - 객실 수: 실제 운영 중인 물리적 객실 수입니다. 재고 관리의 기준이 됩니다.
</Info>

### Step 5. 상품 생성

판매할 상품을 만들어 주세요. 상품은 같은 객실 타입이라도 제공하는 서비스나 이용 조건에 따라 나눠서 설정할 수 있습니다.

<Info>
  **상품 설정 가이드**

  - 룸온니: 숙박만 제공하는 기본 상품입니다.
  - 서비스 포함 상품: 조식, 주차, 패키지 등 부가 서비스를 포함한 상품을 별도로 생성할 수 있습니다. 동일한 객실 타입으로 여러 상품을 만들어 다른 요금으로 판매할 수 있습니다.
</Info>

### Step 6. 숙박업소 생성 완료

숙박업소 등록이 완료되었습니다. 사용 중인 채널을 연동하면 VCMS와 즉시 동기화됩니다.

<Info>
  등록한 정보는 언제든지 숙박업소 설정에서 수정할 수 있습니다. 객실 타입과 상품도 추가·삭제가 가능합니다.
</Info>
