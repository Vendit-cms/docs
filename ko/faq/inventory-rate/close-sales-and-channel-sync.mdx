## 마감이나 요금 변경이 채널에 반영됐는지 어떻게 확인하나요?

> VCMS 판매 관리 화면을 기준으로 확인해 주세요. 동기화 중이고 저장했다면 채널에 적용돼요.

VCMS는 판매 관리에서 저장한 값을 연결된 채널에 보내고, 5분마다 전체 날짜를 확인해 채널 값이 다르면 VCMS 기준으로 다시 맞춰요. 채널에서 직접 바꿔도 5분 안에 VCMS 값으로 돌아와요.

1. 판매 관리의 동기화 상태가 동기화 중인지 확인해 주세요.
   `동기화 중지` 상태에서는 저장해도 채널에 적용되지 않아요.
2. 바꾼 칸에 임시 변경 표시가 남아 있으면 상단의 `저장`을 눌러 주세요.
3. 설정 > 채널 > 연결된 채널 > 채널 상품에서 채널 상품이 VCMS 상품과 연결되어 있고 재고·요금 동기화 배지가 켜져 있는지 확인해 주세요.
4. 설정 > 객실 타입에서 관리 방식이 CMS인지 확인해 주세요.
   `직접 관리`면 예약만 연동되고 재고와 요금은 채널에 적용되지 않아요.

<Note>
  모든 채널이 요금까지 조절되지는 않아요. 리브애니웨어, 반려생활 스테이, 캠퍼레스트처럼 렌트 방식으로 파는 채널과 온다 펜션에서 신규 요금제를 쓰는 숙소는 VCMS에서 요금을 바꿔도 채널에 적용되지 않아요.
</Note>

<Info>
  채널 화면은 채널마다 보이는 방식이 달라요. 판매중지 여부는 캘린더처럼 날짜별 판매 상태가 보이는 화면에서 확인해 주세요. 에어비앤비와 익스피디아는 5분 주기로 연동돼서 저장 직후에는 아직 바뀌지 않았을 수 있어요.
</Info>

<Warning>
  아고다와 연결한 VCMS 상품에 인원별 요금을 설정하지 않으면 판매중지해도 아고다에서 계속 예약 가능으로 남을 수 있어요. 아고다 연결 상품은 인원별 요금을 꼭 설정해 주세요.
</Warning>

그래도 해결되지 않으면 1:1 문의 버튼을 눌러 제보해 주세요.

## 객실 타입을 마감했는데 일부 채널 상품이 안 닫혀요

> 하위 채널 상품에 직접 바꾼 판매 설정이 남아 있는 경우예요. 판매중지할 때 `선택 항목 일괄 변경`을 골라 주세요.

<Info>
  판매 관리는 객실 타입, 상품, 채널 상품 순서로 연결되어 있어요. 상위 항목의 판매 상태를 바꿀 때 하위 항목에 직접 바꾼 설정이 있으면 함께 바꿀지 유지할지 고를 수 있어요.

  - `선택 항목 일괄 변경`: 하위 항목도 모두 같은 값으로 함께 바뀌어요.
  - `직접 변경 항목 유지`: 직접 바꾼 하위 항목의 설정은 그대로 두어요. 직접 판매로 바꿔 둔 채널 상품은 계속 판매돼요.
</Info>

1. 판매 관리에서 해당 객실 타입을 펼쳐 판매 상태가 다른 상품이나 채널 상품을 확인해 주세요.
2. 객실 타입의 판매 상태 칸을 눌러 판매중지로 바꿔 주세요.
3. 변경 방식을 고르는 창이 나오면 `선택 항목 일괄 변경`을 선택해 주세요.
4. 상단의 `저장`을 눌러 채널에 적용해 주세요.

<Note>
  판매를 다시 시작할 때도 같은 창이 나와요. `직접 변경 항목 유지`를 고르면 직접 판매중지해 둔 채널 상품은 판매중지 상태로 남아요.
</Note>

그래도 해결되지 않으면 1:1 문의 버튼을 눌러 제보해 주세요.

## 특정 기간의 판매 상태, 재고, 요금을 한번에 변경하고 싶어요

> 판매 관리의 일괄 변경으로 특정 기간의 판매 상태와 재고, 요금을 동시에 바꿀 수 있어요.

1. 판매 관리에서 `일괄 변경`을 눌러 주세요.
2. 변경 기간과 항목 적용 대상을 선택하고 상단 추가 버튼을 눌러 주세요.
3. 추가된 조건을 확인하고 하단의 `일괄 변경` 버튼을 눌러 주세요.
4. 임시 변경 항목을 확인한 뒤 상단의 `저장`을 누르면 채널에 반영돼요.

<Tip>
  **기간 전체 객실을 판매중지하려면**

  - 적용 대상에서 객실 타입, 상품, 채널 상품을 모두 선택하고 판매 상태를 판매중지로 바꿔 주세요.
  - 며칠만 판매중지할 때는 판매 관리에서 판매 상태 칸을 눌러 바꾸고 저장해도 돼요. 좌우로 끌면 여러 날짜를 한 번에 바꿀 수 있어요.
</Tip>

<Warning>
  - `저장`을 누르지 않고 화면을 벗어나면 임시 변경은 채널에 반영되지 않아요.
  - 연동 기간 밖의 날짜는 채널에 반영되지 않아요. 그 날짜는 채널에서 직접 관리해 주세요.
</Warning>

## 특정 요일만 판매를 막을 수 있나요?

> 네, 판매 관리에서 원하는 요일만 화면에 띄워 판매중지할 수 있어요.

1. 판매 관리에서 `화면 보기 설정`을 열고 요일 선택에서 판매중지할 요일만 골라 주세요.
   예를 들어 금요일과 토요일만 고르면 화면에 그 요일만 보여요.
2. 판매중지할 날짜의 판매 상태 칸을 눌러 판매중지로 바꿔 주세요.
3. 상단의 `저장`을 눌러 채널에 적용해 주세요.
4. 작업이 끝나면 `화면 보기 설정`의 요일 선택을 다시 모든 요일로 돌려 주세요.

<Info>
  요일 선택은 화면에 보이는 날짜만 바꾸고 판매에는 영향을 주지 않아요. 요일 선택을 바꾼 채로 두면 다른 날짜가 사라진 것처럼 보일 수 있어요.
</Info>

## 한 채널에서 예약되면 다른 채널도 자동으로 마감되나요?

> 네, 객실 타입이 CMS 관리이고 동기화 중이면 다른 채널 재고도 함께 줄어요.

한 채널에서 예약이 들어오면 VCMS가 객실 타입의 잔여 재고를 줄이고, 같은 객실 타입에 연결된 다른 채널에도 줄어든 재고를 보내요. 잔여가 0이 되면 연결된 모든 채널 상품의 판매가 멈추고, 예약이 취소되면 재고가 다시 늘어나요.

<Check>
  **자동으로 마감되지 않으면 확인해 주세요**

  - 설정 > 객실 타입에서 관리 방식이 CMS인지 확인해 주세요. `직접 관리`면 예약만 연동되고 재고는 동기화되지 않아요.
  - 판매 관리의 동기화 상태가 동기화 중인지 확인해 주세요. 동기화 중지 상태에서는 예약만 연동돼요.
  - 설정 > 채널 > 연결된 채널 > 채널 상품에서 판매 중인 채널 상품이 모두 VCMS 상품과 연결되어 있는지 확인해 주세요. 연결되지 않은 채널 상품은 재고를 함께 쓰지 않아요.
</Check>

<Info>
  에어비앤비, 떠나요, 야놀자 펜션은 채널 상품 하나가 객실 1개로 팔려요. 재고가 줄면 판매 관리 기준 가장 아래 채널 상품부터 차례로 잔여 수량이 0이 돼요.
</Info>

<Note>
  - 손님이 일찍 체크아웃해도 객실은 자동으로 다시 판매되지 않아요. 팔 수 있다면 판매 관리에서 직접 열어 주세요.
  - 전화나 현장 예약은 VCMS가 알 수 없어요. VCLOUD에 등록하거나 판매 관리에서 재고를 직접 줄여 주세요.
</Note>
