## 연결 끊김 시 확인 사항

### 크롬 확장 프로그램 로그인 상태 확인

<Accordion title="크롬 확장프로그램이 설치된 화면에서 로그인 상태를 확인해 주세요." defaultOpen>
  - 좌측에 고정된 에어비앤비/익스피디아 탭이 열린 크롬 브라우저를 확인해 주세요.
    <Columns cols={2}>
      <Column>
        <Frame>
          ![익스피디아](/images/익스피디아-3.png)
        </Frame>
      </Column>
      <Column>
        <Frame>
          ![에어비앤비 4](/images/에어비앤비-4.png)
        </Frame>
      </Column>
    </Columns>
  - 로그아웃 상태라면 다시 로그인해 주세요.
  - 로그인 후 탭을 닫지 말고 그대로 유지해 주세요. 창은 최소화하셔도 됩니다.
    <Info>
      탭이 열려있어야 벤디트와 동기화가 정상적으로 유지됩니다.
    </Info>
    <Warning>
      좌측에 고정된 탭은 연동 전용입니다. 해당 탭에서 직접 조작하지 마세요. 채널 확인이 필요하면 새 탭을 열어 이용해 주세요.
    </Warning>
</Accordion>
