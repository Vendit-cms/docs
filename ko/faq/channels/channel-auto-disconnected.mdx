---
title: "채널 숙소 연결이 자동으로 해제됐어요"
description: "채널에서 숙소가 비활성화·삭제되거나 공식 연동이 막히면, 잘못된 동기화를 막기 위해 VCMS가 채널 숙소 연결을 자동으로 해제하고 알림으로 안내해 드려요."
---

<Info>
  **왜 채널 숙소 연결이 자동으로 해제되나요?**

  연결된 채널에서 숙소가 비활성화·삭제되거나 공식 연동이 허용되지 않는 상태가 감지되면, 잘못된 예약·요금 동기화를 막기 위해 VCMS가 해당 채널 숙소의 연결을 자동으로 해제해요. 주로 아래와 같은 경우예요.

  - 채널에서 숙소가 비활성화되거나 삭제된 경우
  - 채널매니저(공식 연동) 연결 설정이 되어 있지 않은 경우

  적용 채널은 **아고다, 트립닷컴, 야놀자**이며, 앞으로 순차적으로 확대될 예정이에요.
</Info>

<Check>
  **연결이 해제되면 알림으로 알려드려요**

  연결이 자동으로 해제되면 작업 이력에 기록되고, VCMS 알림과 카카오톡(알림톡)으로 안내해 드려요. 어떤 숙소의 어떤 채널 숙소가 어떤 이유로 해제됐는지 함께 알려드리니, 알림을 받으시면 내용을 확인해 주세요.

  ```text
  [VCMS] 채널 숙소 연결 해제 안내
  {숙소명}의 {채널명}채널 {채널 숙소명}({채널 숙소 ID}) 숙소가
  {해제 사유}로 인해 자동으로 숙소 연결이 해제되었습니다.
  ```
</Check>

<Warning>
  자동으로 해제된 연결은 다시 자동으로 연결되지 않아요. 채널에서 숙소 상태를 정상화하셨다면, VCMS에서 직접 재연결해 주세요.
</Warning>
