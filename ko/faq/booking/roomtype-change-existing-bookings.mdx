## 객실 타입을 추가, 삭제하거나 이름을 바꾸고 싶어요

> 설정 > 객실 타입에서 직접 추가·수정·삭제할 수 있어요. 바꾼 뒤에는 상품과 채널 상품 연결까지 확인해 주세요.

1. 설정 > 객실 타입에서 새 객실 타입을 만들거나 바꿀 객실 타입을 눌러 주세요.
   객실 타입 이름, 객실 정보, 최대 인원 수, 관리 방식을 같은 화면에서 입력하고 수정할 수 있어요.
2. 확인 창이 뜨면 자동으로 조정될 상품 설정을 확인하고 진행해 주세요.
   연결된 상품의 최대 판매 재고, 예약 배수, 인원 설정이 허용 범위에 맞게 자동 조정돼요.
3. 새 객실 타입이라면 상품을 만들고 채널 상품과 연결해 주세요.
   VCMS는 채널에 객실 타입을 만들지 않아요. 채널에도 같은 객실 타입을 등록한 뒤 설정 > 채널 > 연결된 채널 > 채널 상품에서 연결해 주세요.

<Warning>
  **객실 타입 삭제**

  객실 타입은 객실이 하나도 없을 때만 삭제할 수 있고, 삭제하면 연결된 상품도 함께 삭제돼요. 채널 상품이 연결돼 있었다면 먼저 연결을 정리해 주세요.
</Warning>

<Note>
  구독 중에 객실을 추가하면 추가한 만큼의 이용 금액이 결제된 뒤에 적용돼요. 잠시 쉬는 객실은 지우지 말고 운영 중지로 바꿔 주세요.
</Note>

## 객실 타입을 나누면 기존 예약은 어떻게 되나요?

> 타입을 나누거나 객실을 옮기면 타입별 재고 수가 바뀌어요. 판매중지한 상태에서 바꾸고 잔여를 다시 맞춰 주세요.

<Warning>
  판매 중에 객실을 옮기거나 채널 상품 연결을 바꾸면, 그 사이 다른 채널에서 방이 더 팔릴 수 있어요. 꼭 판매중지한 상태에서 바꿔 주세요.
</Warning>

1. 판매 관리에서 바꿀 객실 타입을 판매중지하고 `저장`을 눌러 주세요.
   예약이 있는 날짜만 골라 판매중지해도 돼요.
2. 설정 > 객실 타입에서 새 객실 타입을 만들고 객실을 옮겨 주세요.
3. 새 객실 타입으로 상품을 만들고, 채널에도 같은 기준으로 타입을 나눈 뒤 채널 상품을 다시 연결해 주세요.
4. VCLOUD를 함께 쓴다면 VCLOUD의 객실 타입과 객실 수도 똑같이 맞추고, 기존 예약을 새 타입 객실로 다시 배정해 주세요.
5. 판매 관리에서 날짜별 잔여가 실제 남은 방 수와 맞는지 확인한 뒤 다시 판매로 바꿔 주세요.

<Note>
  채널에서 객실 타입을 지워도 그 타입으로 이미 받은 예약은 채널에 남아 있을 수 있어요. 지운 뒤에는 채널 예약 목록과 VCMS 예약 내역을 비교해 빠진 예약이 없는지 확인해 주세요.
</Note>

그래도 해결되지 않으면 1:1 문의 버튼을 눌러 제보해 주세요.
