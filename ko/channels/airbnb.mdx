에어비앤비를 연결하기 전에 아래 항목을 확인해 주세요.

---

<Check>
  **사전 준비 사항**

  - 연동할 에어비앤비 계정
  - 크롬 브라우저
  - 안정적인 인터넷 연결 환경
</Check>

### Step 1. 크롬 브라우저에서 에어비앤비 로그인

크롬 브라우저를 열고 에어비앤비에 접속하여 파트너 계정으로 로그인합니다.

1. 크롬 브라우저를 실행합니다.
2. [에어비앤비](https://www.airbnb.co.kr/?c=.pi0.pk127647725_5917950125&localized_ghost=true&gad_source=1&gad_campaignid=127647725&gbraid=0AAAAADz55LmZfMSAtsFWxPbvWk0UGKGgC&gclid=CjwKCAjwwJzPBhBREiwAJfHRnRgtSM4jpmhEG9_KDrE2PtbN5vAqT8dJzIFGuc7f3E7gJVeHCFjiEhoCg7oQAvD_BwE) 사이트에 접속합니다.
3. 계정 정보를 입력하여 로그인합니다.
4. 로그인이 완료되면 해당 탭을 유지합니다.(탭을 닫지 마세요.)

<Frame>
  ![Airbnb Host Mode](/images/airbnb-host-mode-4.png)
</Frame>

<Tip>
  로그인한 탭은 연동이 완료된 후에도 계속 열어두어야 합니다. 탭을 닫으면 동기화가 중단됩니다.
</Tip>

<Warning>
  에어비앤비 탭 조작 주의

  - 크롬 좌측에 고정된 에어비앤비 탭은 연동을 진행하고 있습니다.\
    안정적인 연동을 위해 최대한 조작을 지양해 주세요.
  - 에어비앤비 정보를 확인하려면 고정된 탭이 아닌 새 탭에서 별도로 접속해 주세요.
</Warning>

---

### Step 2. 크롬 확장 프로그램 설치

크롬 웹스토어에서 VCMS 확장 프로그램을 설치하고 실행합니다.

<Tip>
  이미 확장 프로그램이 설치되어 있다면 이 단계를 건너뛰고 Step 3으로 진행해 주세요.
</Tip>

1. 확장 프로그램을 설치합니다.
2. 브라우저 우측 상단의 퍼즐 아이콘을 클릭합니다.
3. VCMS 확장 프로그램을 클릭하여 실행합니다.

<Frame>
  ![Chrome Extension](/images/chrome-extension.png)
</Frame>

---

### Step 3. 확장 프로그램 실행 및 설정

확장 프로그램 내에서 VCMS 계정으로 로그인하고, 숙소를 선택한 후 에어비앤비의 '사용하기' 버튼을 클릭합니다.

1. VCMS 계정으로 로그인합니다.
2. 연결할 숙소를 선택합니다.
3. 에어비앤비 사용하기 버튼을 클릭합니다.

<Warning>
  **반드시 확인해 주세요.**

  - '사용하기' 버튼을 클릭하기 전에 반드시 크롬에 에어비앤비가 로그인 되어 있어야 합니다.
  - Step 1에서 열어둔 에어비앤비 탭이 정상적으로 유지되고 있는지 확인해 주세요.
</Warning>

---

### Step 4. VCMS에서 에어비앤비 숙소 연결 및 상품 매핑

VCMS로 돌아와 에어비앤비 숙소를 연결하고 상품을 매핑하면 연결이 완료됩니다.

<Warning>
  **에어비앤비 매핑 전 반드시 확인해 주세요.**

  - VCMS와 에어비앤비를 연결하면 에어비앤비에서 설정한 프로모션이 초기화 됩니다.
  - 매핑하기 전 VCMS 판매 관리에서 재고, 요금 설정을 먼저 완료해 주세요.
  - 판매관리 설정이 완료되지 않은 상태에서 매핑하면 의도하지 않은 재고, 요금이 에어비앤비에 반영될 수 있습니다.
</Warning>

1. VCMS의 '채널' 메뉴로 이동합니다.
2. 에어비앤비 채널을 선택합니다.
3. 사용 중이신 숙소를 연결합니다.
4. 에어비앤비 상품에 대응하는 VCMS 상품을 연결합니다.
5. 모든 매핑이 완료되면 '저장' 버튼을 클릭합니다.

<Tip>
  상품 매핑은 연결 이후에도 VCMS 채널 설정에서 언제든 수정할 수 있습니다.
</Tip>

## 연결 완료 후 유의사항

채널 연결이 완료되면 예약, 재고, 요금 정보가 자동으로 동기화됩니다. 안정적인 동기화를 위해 아래 사항을 반드시 준수해 주세요.

| 항목 | 설명 | 주의 |
| --- | --- | --- |
| 크롬 브라우저 | 확장 프로그램이 실행 중인 크롬을 닫지 마세요. | 닫으면 동기화 중단 |
| 에어비앤비 탭 | 로그인된 채널 탭을 유지해 주세요. | 닫으면 동기화 중단 |
| 컴퓨터 전원 | 컴퓨터가 반드시 켜져 있어야 합니다. | 종료시 동기화 중단 |

<Warning>
  **중요 안내**

  - 채널 연결 이후 크롬 브라우저 또는 에어비앤비 탭을 닫으면 동기화가 중단됩니다.
  - 컴퓨터를 재부팅하신 경우, 반드시 크롬 브라우저와 에어비앤비 탭을 열고, 다시 로그인해 주세요.
  - 에어비앤비 예약/재고/요금 연동 주기는 5분입니다.
</Warning>

<Warning>
  다지점 운영 시 주의사항

  - 다지점(여러 숙소)을 운영하는 경우, 하나의 크롬 탭에서 여러 계정의 에어비앤비를 로그인하면 충돌이 발생할 수 있습니다.
  - 서로 다른 PC, 다른 브라우저(엣지, 사파리 등), 다른 크롬 프로필 탭에서\
    숙소별 에어비앤비 로그인을 진행해 주세요.
</Warning>

## 자주 묻는 질문

<Accordion title="컴퓨터 재부팅하거나 크롬을 실수로 닫은 경우 어떻게 하나요?">
  크롬을 다시 실행해 주시면, 에어비앤비 탭이 자동으로 열립니다.
</Accordion>

<Accordion title="동기화 주기는 어떻게 되나요?">
  에어비앤비의 동기화 주기는 5분입니다. 연동이 정상적으로 유지되고 있다면 해당 주기마다 예약, 재고, 요금 정보가 자동으로 동기화됩니다.
</Accordion>

<Accordion title="여러 지점을 운영하고 있으면, 어떻게 하나요?">
  크롬 프로필 한 개당 하나의 숙소만 연결 가능합니다. 크롬 프로필을 추가하여 STEP 1 → STEP4 과정을 진행해 주세요.
</Accordion>

<Accordion title="재고만 연동하는 것도 가능한가요?">
  설정 → 채널 → 채널 상품에서 요금 동기화를 비활성화하면, 재고만 연동됩니다. 요금은 에어비앤비에서 직접 관리해 주세요.
</Accordion>

<Accordion title="에어비앤비 연동이 끊겼다는 알림을 받았어요.">
  크롬 좌측 에어비앤비 탭에서 로그인을 진행해 주시면 정상적으로 연동됩니다. 지속적으로 알림이 수신되면, 업장 네트워크 환경을 확인해주세요.

  <Frame>
    ![Airbnb Sign In](/images/airbnb-sign-in.png)
  </Frame>
</Accordion>

<Accordion title="확장 프로그램은 이미 설치되어 있습니다. 다시 설치해야 하나요?">
  경우에 따라 다릅니다.

  <Accordion title="설치가 필요 없는 경우" defaultOpen>
    다른 채널(예: 익스피디아)을 기존에 연결하여 이미 확장 프로그램이 설치된 상태에서, 같은 숙소에 에어비앤비를 추가 연동하는 경우 설치가 필요 없습니다. Step 2를 건너뛰고 Step 3부터 진행해 주세요.
  </Accordion>

  <Accordion title="다시 설치가 필요한 경우" defaultOpen>
    다지점을 운영하여 같은 채널에 다른 숙소를 2개 이상 연결하는 경우, 크롬 프로필을 분리하고 각 프로필에 확장 프로그램을 별도로 설치해야 합니다.
  </Accordion>
</Accordion>
